# 🏠 AirDNB – Command-Line Airbnb Clone

AirDNB is a command-line application that mimics the core features of Airbnb. It allows users to browse, list, and book rental properties entirely through a terminal interface. Built with Python and SQLite, it supports user registration, property management, and reservation tracking in a persistent local database.

## 📦 Features

- 🔑 **User Authentication**: Sign up, log in, and manage user profiles.
- 🏘️ **List Properties**: Hosts can create, update, and delete their listings.
- 🔍 **Browse & Search**: Guests can browse available properties by filters.
- 📅 **Book Stays**: Users can make, view, or cancel reservations.
- 🗃️ **SQLite Database**: All data is stored locally and persistently.

## 🧰 Technologies Used

- Python 3
- SQLite
- Bash (for setup scripts)
- Object-Oriented Programming (OOP) Design
