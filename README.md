# 🏡 AirDNB – A CLI-Based Airbnb Clone

**AirDNB** is a command-line interface (CLI) project that simulates a simplified version of Airbnb. Users can add listings, register accounts, make and manage reservations, rate stays, and more — all from the terminal. It uses a SQLite database to persist user, listing, and reservation data.

## 🧩 Features

- 🔐 **User Registration & Login**
- 🏠 **Create & Manage Listings**
- 📅 **Reserve and Cancel Bookings**
- ⭐ **Rate Listings & View Ratings**
- 🔎 **Search Listings by Name or Day**
- 🤝 **Track User & Listing Reservations**
